### 1.3 响应式断点

| 窗口宽度 | 布局策略 |
| :--- | :--- |
| ≥ 1400px | 标准三栏：连接点(280px) + 预览(min-55%) + 清洗(260px) + Minimap(30px) |
| 1024-1399px | 两栏：预览 + 清洗；Minimap 隐藏；连接点面板折叠为侧边抽屉 |
| < 1024px | 单栏堆叠；芯片栏横向滚动；清洗面板折叠为图标按钮 |

## 二、各区域详细说明

### 2.1 标题栏（TitleBar）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | 左侧汉堡菜单 [≡] + 应用标题「文档终版确定器 — Text Unifier v4.0」+ 右侧窗口控制按钮 |

### 2.2 模式切换标签栏（ModeTabs）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | 40px 高度，左侧两个 Tab + 右侧 UploadButton |
| **核心元素** | Tab「🔗 合并去重」、Tab「📋 文档对比」、`+` 按钮(36×36px) |
| **交互逻辑** | 点击 Tab 切换模式，选中 Tab：白色底 + 蓝色下划线（3px）；未选中：灰色文字；`+` 按钮始终可见，点击触发文件选择对话框（`input[type=file]`，accept=".txt"，multiple） |
| **字段规则** | 对比模式下连接点列表、清洗面板隐藏；合并模式下 DiffView 隐藏 |
| **异常提示** | 切换到对比模式时文件数 > 2 → 弹出 Modal 警告「文档对比仅支持 2 个文件，请先移除多余文件」；文件数 < 2 → 允许切换但显示空状态提示 |

### 2.3 拖拽遮罩层（DragOverlay）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | `position: fixed; inset: 0; z-index: 50`，全窗口覆盖层 |
| **核心元素** | 半透明背景 + 居中白色圆角卡片 + 图标 + 提示文字 |
| **交互逻辑** | dragenter(dragEnterCounter++) → 显示遮罩；dragleave(dragEnterCounter--) → counter=0 时隐藏；drop → 隐藏遮罩 + 处理文件 |
| **字段规则** | 正常拖入 .txt → `bg-blue-500/20 backdrop-blur-sm` + 📄 图标 + 「释放到此添加 TXT 文件」；拖入非 .txt → `bg-red-500/20` + 🚫 图标 + 「仅支持 .txt 文件」 |
| **异常提示** | 拖入混合文件(.txt+.png) → 红色遮罩，仅接受 .txt 部分；全部非 .txt → 红色遮罩，Toast「未添加任何文件：仅支持 .txt 格式」 |

### 2.4 文件芯片栏（FileChipBar）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | 40px 高度，`overflow-x: auto; overflow-y: hidden`，`white-space: nowrap` |
| **核心元素** | FileChip × N（draggable）+ AddButton（36×36px，固定末尾） |
| **交互逻辑** | 芯片支持横向拖拽排序（onDragEnd → reorderFiles → triggerReanalysis）；点击芯片 × → removeFile；空芯片栏时显示占位提示「点击 + 或拖拽文件到此处」 |
| **字段规则** | 文件名截断 20 字（CSS `text-overflow: ellipsis` + `max-width: 160px`）；大小标签：B(<1024)、KB(≥1024)、MB(≥1048576)，保留 1 位小数 |

#### 2.4.1 文件芯片（FileChip）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | `rounded-full text-xs bg-blue-50 border border-blue-200 px-3 py-1.5`，flex 水平排列 |
| **核心元素** | 📄 文件图标 + 文件名（截断） + 大小标签 + ★ 主文件徽章（仅第 1 个）+ × 删除按钮 |

### 2.5 连接点列表（ConnectionPointList）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | 左侧面板，默认宽 280px，右边缘可拖拽调整（200px~500px），`overflow-y: auto`。顶部标题「连接点 (N)」+ 齿轮图标(⚙)进入合并设置 |
| **核心元素** | ConnectionPointItem 列表 |

| **字段规则** | 空状态-单文件：「仅一个文件，无需合并」；空状态-无重叠：「✨ 所有文件连接处无重叠」；搜索时面板临时切换为搜索结果列表，标题变为「搜索结果 (N)」 |

#### 2.5.1 连接点项（ConnectionPointItem）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | `border-b border-gray-100 py-2 px-3`，状态标识 + snippet + 文件对 + 操作开关 |
| **核心元素** | 状态底色（灰/高亮）、snippet（重叠文本截断前 15 字）、文件对标签（`文件A ↔ 文件B`）、重叠长度标签、切换开关 |
| **交互逻辑** | 悬停 snippet 300ms → Tooltip 完整重叠文本 + 前后各 50 字上下文；点击开关 → 切换合并/保留状态 → 预览区即时更新 |
| **字段规则** | 自动合并（≥阈值）：灰色底色 + 「已自动合并」标签 + 开关默认开；待确认（<阈值）：高亮(蓝)底色 + 「待确认(N字重叠)」标签 + 开关默认关 |
| **异常提示** | 切换开关操作失败 → 静默回退；文件被删除 → 对应连接点自动移除 |

### 2.6 预览面板（PreviewPanel）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | 中间主区域，`flex-1 min-w-[55%]`，连续文本可编辑区 + 右侧 Minimap(30px) |
| **核心元素** | 连续文本编辑区 + 连接标记 + Minimap |
| **交互逻辑** | 文本可编辑；滚动时 Minimap 同步高亮当前位置；连接标记不可编辑 |
| **字段规则** | 合并后文本为连续字符串；连接标记显示为不可编辑的装饰性分隔符 |

#### 2.6.1 连接标记（ConnectionMarker）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | `text-center py-1 my-2 border-t border-b border-dashed`，灰色(自动合并) 或 蓝色(待确认) |
| **核心元素** | 标记文字「┈┈ 连接 (文件A ↔ 文件B, N字重叠) ┈┈」+ 「切断」/「连接」按钮 |
| **交互逻辑** | 点击「切断」→ 连接断开，原文双重叠恢复；点击「连接」→ 恢复合并态，重叠删除 |
| **字段规则** | 自动合并态：灰色标记 + 「已自动合并」+ 显示「切断」按钮；待确认态：蓝色高亮标记 + 「待确认」+ 显示「连接」按钮（默认断开态）/「切断」按钮（已手动合并态）；导出时连接标记不写入文件 |
| **异常提示** | 无法确定合并/断开状态 → 保持当前状态 |

#### 2.6.2 缩略图（Minimap）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | 右侧 30px 宽，`position: sticky; top: 0`，高度 = 预览区可视高度 |
| **核心元素** | N 个色条均匀铺满 Minimap 高度。每个色条视觉规格 2px 高 + 1px 间距；**N 由 Minimap 容器高度决定**（N ≈ 容器高度 / 3），每个色条代表全文被等分为 N 份后的一份区域。连接点所在比例位置的色条 = 黄色(自动合并) / 蓝色(待确认) |
| **映射规则** | **等比例压缩**：全文总高度 → Minimap 容器高度。第 i 个色条对应全文 `i/N` 比例位置。点击第 i 个色条 → 预览区 `scrollTop = 全文总高度 × (i/N)` |
| **交互逻辑** | 悬停 → 高亮当前色条；点击 → 预览区平滑滚动到对应比例位置 |
| **字段规则** | 窗口宽度 < 1024px 时隐藏。色条默认灰色，连接点处黄色/蓝色 |

#### 2.6.3 悬停溯源 Tooltip

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | `absolute`，白色圆角卡片 + 阴影，`max-w-72` |
| **核心元素** | 来源文件信息 |
| **交互逻辑** | 悬停 300ms 后出现，跟随鼠标 + 8px 偏移；边界检测自动翻转方向 |
| **字段规则** | 普通文本：「来源：文件A.txt」；连接点处：「重叠区：文件A ↔ 文件B (N字重叠)」 |
| **异常提示** | 无来源数据 → 不显示 Tooltip |

#### 2.7.1 ToggleButton（双向切换按钮）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | `w-full h-10 rounded-lg text-sm font-medium flex items-center justify-center gap-2` |
| **核心元素** | 箭头图标（→ / ←）+ 文字标签 + 状态颜色背景 |
| **交互逻辑** | 点击 → 执行转换 → 翻转箭头 + 切换颜色；再点击 → 反向转换 → 恢复初始状态 |
| **字段规则** | 未转换态：`bg-blue-500 text-white`，箭头 →，标签「全→半」/「繁→简」；已转换态：`bg-gray-500 text-white`，箭头 ←，标签「半→全」/「简→繁」 |
| **异常提示** | 繁简引擎首次加载（懒加载）→ Toast「正在启动繁简引擎…」+ 按钮显示 Spinner + disabled，加载完成后自动执行转换；引擎加载失败 → Toast「繁简引擎启动失败，请重启应用」，按钮保持未转换态 |

#### 2.7.2 搜索替换区（SearchReplace）

| 属性 | 说明 |
| :--- | :--- |
| **页面结构** | 分隔线下方，搜索输入框 + 替换输入框 + 「区分大小写」复选框 + 「替换」/「全部替换」按钮 + 匹配计数 |
| **核心元素** | 搜索框（带 × 清除按钮）、替换框、操作按钮行、「第 M/N 个」计数标签 |
| **交互逻辑** | 输入搜索关键词 → 实时高亮预览区匹配项（黄色底色，当前焦点橙色） + 左侧面板切换为搜索结果列表；点击「替换」→ 替换当前焦点项 → 自动跳至下一项；点击「全部替换」→ 全部替换 → Toast「已替换 N 处」；清空搜索框或点击 × → 左侧面板恢复为连接点列表 |
| **字段规则** | 搜索结果面板：每条结果显示前后各 15 字上下文 + 点击跳转；区分大小写默认关闭 |
| **异常提示** | 无匹配项 → 结果面板显示「未找到匹配项」；搜索框为空 → 无高亮，面板恢复为连接点列表 |

#### 2.9.2 统计栏（DiffStats）

| 属性 | 说明 |

| **交互逻辑** | 无交互 |
| **字段规则** | 格式：「共有 N 段 | 左独有 M 段 | 右独有 K 段 | 差异 D 段」 |
| **异常提示** | LCS 对齐失败 → 全部标记为差异(灰色)；Levenshtein 计算超时(>5s/段落) → 标记为左/右独有 |

## 七、异常状态与提示文案汇总

| 场景 | 触发条件 | 提示方式 | 文案 |
| :--- | :--- | :--- | :--- |
| 格式拒绝 | 拖入/选择非 .txt 文件 | Toast (3s) | 「仅支持 .txt 文件」 |
| 重复文件 | 添加已存在的文件 | Toast (3s) | 「文件已存在」 |
| 文件过大 | 单文件 > 200MB | Toast (5s) | 「文件过大(>200MB)，可能导致性能下降」 |
| 文件过多 | 文件数 > 50 | Toast (3s) | 「最多支持 50 个文件」 |
| 短重叠通知 | 检测到 1~49 字重叠 | Toast (5s) | 「检测到 N 处短重叠，请在连接点面板中确认」 |
| 超大文本 | 合并后 > 1,000,000 字 | 预览顶部 Banner | 「文本较长(N字)，已启用虚拟滚动优化」 |
| 编码失败 | 编码探测全部失败 | 静默兜底 UTF-8 | （无提示） |
| 对比文件限制 | 对比模式文件 > 2 | Modal | 「文档对比仅支持 2 个文件，请先移除多余文件」 |
| 对比单文件 | 对比模式仅 1 文件 | 内容区文字 | 「请添加第二个文件以进行对比」 |
| 空导出 | 预览区无内容 | Toast (3s) | 「没有可导出的内容」 |
| 磁盘不足 | 导出路径磁盘满 | Toast (5s) | 「磁盘空间不足，无法导出」 |
| 引擎加载中 | 首次繁简转换 | Toast (3s) | 「正在启动繁简引擎…」 |

| 核心引擎失败 | 核心引擎加载失败 | 启动 Modal | 「核心引擎加载失败，请重新安装」 |
| 文件读取失败 | 文件读取异常 | Toast (3s) | 「读取失败：{文件名}」 |
| 阈值无效 | 输入超出 10~500 | Toast (3s) | 「阈值范围 10~500」 |
| 搜索无匹配 | 关键词不存在于文本 | 搜索结果面板 | 「未找到匹配项」 |
| 无文件 | 未添加任何文件 | 预览区 | 「拖拽 .txt 文件到此处或点击 + 按钮添加」 |
