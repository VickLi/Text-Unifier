# 产品需求文档（PRD）— 文档终版确定器 Text Unifier V4.0

> **版本**: V4.0（项目重构版，基于 V1.0~V3.3 全量需求整合）
> **文档类型**: 标准化 PRD（6 章格式，适配架构设计 AI 输入）
> **目标平台**: Windows 10 / 11 / macOS 12+ / Linux
> **重构说明**: 删除章节工具模块（F）、排版增强模块（G）；内容清洗精简为繁简转换 + 全角半角转换

---

## 一、项目概述

### 1.1 核心目标

Text Unifier V4.0 是一款**完全离线的桌面工具**，基于 V1.0~V3.3 六代迭代重构。核心定位为：**多 TXT 文件合并去重、内容清洗、预览编辑、文档对比、一键导出**。

### 1.2 目标用户

| 用户角色 | 典型场景 | 核心需求 |
| :--- | :--- | :--- |
| 网文读者/整理者 | 多源 TXT 小说合并，去除重复章节 | 文件间去重、主文件完整保留、导出纯净 TXT |
| 文档编辑/校对 | 多版本文档对比差异 | 双栏对比、差异高亮、同步滚动 |
| 文本处理者 | TXT 文件繁简转换、全半角转换 | 双向切换、批量处理、离线操作 |

### 1.3 核心价值

- **100% 离线**：不上传任何数据，所有处理在本地完成
- **智能合并**：字符级链式重叠合并，自动拼接文件衔接处的重复内容，内部重复完整保留
- **可视化操作**：可编辑预览、拖拽排序、悬停溯源、Minimap 缩略图
- **完全可控**：连接点切断/连接、撤回/重做、文档对比，每一步都可审查可回退
- **跨平台兼容**：支持 Windows 10+、macOS 12+、Linux 主流发行版

## 三、核心业务流程图

### 3.1 完整处理流水线

```mermaid
flowchart TD
    A["用户添加 .txt 文件<br/>(拖拽/按钮)"] --> B{"格式校验<br/>仅 .txt?"}
    B -->|否| B1["拒绝 + 提示<br/>'仅支持 .txt 文件'"]
    B -->|是| C["芯片栏排序<br/>确定主文件(第1个)"]
    C --> D{"文件数 > 1?"}
    D -->|否| D1["直接输出原文<br/>跳过去重"]
    D -->|是| E["Phase 1: 前端预处理<br/>E1. 繁简转换(若启用)<br/>E2. 全角↔半角转换(若启用)"]
    E --> F["Phase 2: 归一化<br/>B1. 换行统一, 空格压缩<br/>B2. 编码探测链<br/>UTF-8→GB18030→Win1252→SJIS"]
    F --> G["Phase 3: 链式重叠合并<br/>result = 文件[0]全文<br/>依次对后续文件做最长后缀-前缀匹配<br/>≥阈值: 自动合并删除重叠<br/><阈值: 原文拼接+提示用户"]
    G --> H["Phase 4: 合并输出<br/>连续文本预览 + 连接标记<br/>连接点列表<br/>Minimap"]
    H --> I["用户交互<br/>连接点切断/连接/编辑/撤回/清洗/排序"]
    I --> J["导出 .txt<br/>UTF-8, 预览区完整文本<br/>（排除连接标记）"]
    D1 --> H
```

### 3.2 链式重叠合并算法（V4.0）

```mermaid
flowchart TD
    START["输入: 已排序文件列表"] --> INIT["归一化所有文件<br/>result = 文件[0]全文"]
    INIT --> LOOP{"还有后续文件?<br/>i = 1 to N-1"}
    LOOP -->|是| LCS["查找最长公共子串:<br/>result后缀 ∩ 文件[i]前缀"]
    LCS --> CHECK{"重叠长度 L ?"}
    CHECK -->|"L >= 文件[i]全长"| SKIP["完全包含<br/>跳过文件[i]"]
    CHECK -->|"L >= 阈值(默认50)"| AUTO["自动合并:<br/>result += 文件[i][L:]"]
    CHECK -->|"1 <= L < 阈值"| SHORT["短重叠提示:<br/>result += 文件[i]全文<br/>加入连接点待确认列表"]
    CHECK -->|"L = 0"| NONE["无重叠:<br/>result += 文件[i]全文"]
    SKIP --> LOOP
    AUTO --> LOOP
    SHORT --> LOOP
    NONE --> LOOP
    LOOP -->|否| DONE["输出: result + 连接点列表<br/>(每个连接点含重叠信息<br/>与合并/保留状态)"]
```

### 3.3 连接点决策流程

```mermaid
flowchart TD
    CP["检测到连接点<br/>(重叠长度 L)"] --> CHECK{"L >= 阈值?"}
    CHECK -->|是| GRAY["灰色连接点<br/>自动合并态<br/>用户可手动切断"]
    CHECK -->|否| HIGHLIGHT["高亮连接点<br/>待确认态<br/>默认保留(原文双重叠)"]
    GRAY --> TOGGLE1{"用户操作?"}
    HIGHLIGHT --> TOGGLE2{"用户操作?"}
    TOGGLE1 -->|"点击「切断」"| CUT["断开连接<br/>原文双重叠恢复"]
    TOGGLE1 -->|"不操作"| KEEP_AUTO["保持自动合并"]
    TOGGLE2 -->|"点击「合并」"| MERGE["手动合并<br/>删除重叠部分"]
    TOGGLE2 -->|"不操作"| KEEP_FULL["保持原文(双重叠)"]
    CUT --> UPDATE["预览区即时更新"]
    MERGE --> UPDATE
    KEEP_AUTO --> UPDATE
    KEEP_FULL --> UPDATE
```

### 3.4 撤回/重做流程

```mermaid
flowchart TD
    OP["用户操作<br/>(清洗/编辑/连接点切换)"] --> DEBOUNCE["debounce 500ms"]
    DEBOUNCE --> SNAP["拍摄快照<br/>深拷贝:<br/>mergedText + connectionStates + modifiedFlags"]
    SNAP --> PUSH["push 到 UndoStack<br/>栈满(5步) → FIFO 出队"]
    PUSH --> UPDATE["undoPointer = 栈顶"]

    CTRL_Z["Ctrl+Z"] --> CAN_UNDO{"undoPointer > 0?"}
    CAN_UNDO -->|是| UNDO["pointer--<br/>恢复 Snapshot[pointer]"]
    CAN_UNDO -->|否| IGNORE_Z["忽略(栈底)"]

    CTRL_Y["Ctrl+Y"] --> CAN_REDO{"undoPointer < 栈深度-1?"}
    CAN_REDO -->|是| REDO["pointer++<br/>恢复 Snapshot[pointer]"]
    CAN_REDO -->|否| IGNORE_Y["忽略(栈顶)"]
```

## 六、非功能需求

### 6.1 性能需求

| 指标 | 要求 | 说明 |
| :--- | :--- | :--- |
| 单文件大小上限 | ≤ 200MB | 超过时 Toast 警告「文件过大(>200MB)，可能导致性能下降」，仍允许添加 |
| 最大文件数 | ≤ 50 个 | 超过时拒绝并提示「最多支持 50 个文件」 |
| 合并处理时间 | ≤ 30s（10 文件 × 10MB） | 处理期间显示进度 Spinner + 「正在合并…」 |
| 预览渲染 | ≤ 5000 段落流畅滚动 | 超过时启用虚拟滚动降级策略 |
| 首屏加载 | ≤ 3s | 应用启动到可交互 |
| 内存占用 | ≤ 500MB（常规使用） | 10 文件 × 10MB 场景 |

### 6.2 安全需求

| 指标 | 要求 |
| :--- | :--- |
| 数据隐私 | 100% 离线，不发起任何网络请求；所有文本处理在本地完成 |
| 文件访问 | 仅读取用户主动添加的 .txt 文件；不访问其他路径或文件类型 |
| 依赖审计 | 繁简转换字典内嵌打包，无运行时外部下载；仅加载本地资源 |
| 内容安全 | 不修改原始文件，仅写入用户指定的导出路径 |
| 进程隔离 | 渲染进程沙箱隔离，无系统级权限 |

### 6.3 兼容性需求

| 指标 | 要求 |
| :--- | :--- |
| Windows | 10 / 11（x64） |
| macOS | 12+（x64 / arm64） |
| Linux | 主流发行版（x64，AppImage / deb） |
| 编码支持 | UTF-8、UTF-16 LE/BE、GB18030/GBK/GB2312、Windows-1252、SHIFT-JIS |
| 文件扩展名 | 仅 `.txt`（大小写不敏感：.txt / .TXT） |

### 6.4 可靠性需求

| 指标 | 要求 |
| :--- | :--- |
| 错误处理 | 文件读取失败 → Toast 提示 + 跳过该文件，不影响其他文件 |
| 核心引擎 | 核心引擎加载失败 → 启动时弹窗「核心引擎加载失败，请重新安装」，阻止进入主界面 |
| 磁盘空间 | 导出路径磁盘不足 → Toast「磁盘空间不足，无法导出」 |
| 崩溃恢复 | 应用崩溃 → 下次启动不自动恢复状态（无持久化设计） |

### 6.5 可用性需求

| 指标 | 要求 |
| :--- | :--- |
| 界面语言 | 简体中文 |
| 快捷键 | Ctrl+Z(撤回)、Ctrl+Y(重做)、Ctrl+S(导出)、Ctrl+A(全选)、Shift+Click(多选) |
| Tooltip 延迟 | 300ms（悬停触发） |
| 响应式 | ≥1400px 三栏 / 1024-1399px 两栏 / <1024px 单栏 |
