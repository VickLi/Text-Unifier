## 构建与启动

```powershell
# 1. 安装依赖
cd 03-code
npm install

# 2. 编译 Rust 原生模块
npx --no-install napi build --release --platform --cargo-cwd native

# 3. TypeScript 类型检查
npx --no-install tsc --noEmit --project tsconfig.json

# 4. 前端构建
npx --no-install vite build

# 5. Electron 开发模式
npm run electron:dev

# 6. Electron 生产打包
npm run electron:build
```
