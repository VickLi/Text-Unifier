## 项目隐私安全审查报告

根据前期发现的隐私安全问题，生成以下两份交付物：

### 1. 项目隐私安全审查报告.md

详细的 MD 格式隐私安全审查报告，记录项目代码中发现的隐私泄露风险点。格式仿照已有的 `项目精简清理报告.md` 和 `项目第二轮精简清理报告.md` 的风格（表格化、分类清晰）。

### 2. AI_PRIVACY_CHECK.md

供后续 AI 读取的简短提示词文件，列明推送 GitHub 前的隐私检查清单，避免再度出现隐私泄露。

### 报告内容覆盖范围

- 高风险项（真实姓名、邮箱）
- 中风险项（绝对路径、开发环境配置）
- 低风险项（Git 备份目录、用户名关联）
- 检查通过项（API 密钥、私钥、数据库信息等）
- 每项包含：文件位置、具体内容、风险等级、修复建议

## 技术方案

### 实现方式

- 不修改现有代码，仅新增两个文档文件
- 报告格式沿用已有报告风格（Markdown 表格、分节、每项含说明表格），保持项目文档一致性
- 提示词放在 `.md` 文件中，便于后续 AI 读取

### 关键决策

- 提示词不使用 `.clinerules` / `.cursorrules`（项目中不存在，且当前环境为 CodeBuddy 不适用）
- 使用 `AI_PRIVACY_CHECK.md` 文件，简洁明了，AI 可直接读取并执行

### 目录结构变更

项目根目录新增 2 个文件：

```
项目隐私安全审查报告.md   [NEW] 隐私安全问题审计报告
AI_PRIVACY_CHECK.md       [NEW] AI 隐私检查提示词
```

忽略 - 纯文档生成任务，无需 UI 设计
