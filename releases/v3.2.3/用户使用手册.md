# Text Unifier — 用户使用手册

> **版本**: v3.2.3  
> **适用平台**: Windows 7 SP1 ~ Windows 11 (x64)  
> **技术架构**: Electron 31 + napi-rs (Rust) + React 18

---

## 一、安装说明

### 便携版（推荐）

1. 下载 `TextUnifier_Portable_v3.2.3.zip`
2. 解压到任意目录（建议：`C:\Program Files\TextUnifier\` 或桌面）
3. 双击 `Text Unifier.exe` 启动
4. （可选）右键 `Text Unifier.exe` → 固定到任务栏 / 发送到桌面快捷方式

### 安装版（批处理脚本）

1. 解压便携版 ZIP 到任意目录
2. 以 **管理员身份** 运行 `installer\安装程序.cmd`
3. 按提示选择安装路径（默认 `C:\Program Files\TextUnifier\`）
4. 安装完成后桌面自动创建快捷方式

---

## 二、卸载说明

### 便携版

直接删除解压目录即可。如已创建快捷方式，手动删除。

### 安装版

1. 删除安装目录（默认 `C:\Program Files\TextUnifier\`）
2. 删除桌面快捷方式

> **注意**：本应用为绿色软件，不写注册表，卸载仅需删除文件。

## 三、快速入门

### 3.1 添加文件

| 方式 | 操作 |
|:---|:---|
| **拖拽** | 从 Windows 资源管理器将 `.txt` 文件拖入应用窗口 |
| **点击添加** | 点击芯片栏末尾的 `+` 按钮，在文件对话框中选择 `.txt` 文件 |

> 支持多选文件，支持 `.txt` 格式。

### 3.2 合并去重模式

**功能**：检测多个 `.txt` 文件中的重复段落，合并为去重后的单一文档。

操作流程：
1. 添加 2 个或更多 `.txt` 文件
2. 左侧「重复段落」面板列出所有重复组
3. 勾选/取消勾选需要保留或排除的段落
4. 点击底部 ⏎ 导出按钮保存结果

### 3.3 文档对比模式

**功能**：左右双栏对比两个文件的内容差异。

操作流程：
1. 添加 2 个 `.txt` 文件
2. 切换到「文档对比」标签
3. 查看差异：🟢 匹配 / 🔴 左独有 / 🔵 右独有

### 3.4 章节识别与内容清洗

**功能**：自动识别章节标题，支持繁简转换、全角半角转换、广告过滤。

操作流程：
1. 添加文件并完成分析
2. 右侧「工具」面板选择「清洗」标签
3. 使用双向切换按钮执行全角⇄半角、繁⇄简转换
4. 开启广告过滤开关，输入过滤关键词
5. 切换到「章节」标签查看章节结构
6. 切换到「排版」标签执行文档排版

## 四、功能介绍

### 4.1 文件管理
- **文件排序**：拖拽芯片调整文件顺序
- **主文件**：第一颗芯片标记为 ★ 主文件，影响文档排版方向
- **删除文件**：点击芯片上的 ✕ 按钮

### 4.2 段落勾选
- **单段勾选**：点击段落前的 ☐/☑
- **批量勾选**：按住 Shift 点击多段
- **全选/取消**：底部工具栏 ☐ 全选 / ☑ 取消全选

### 4.3 导出
- 点击 ⏎ 导出
- 选择保存路径和文件名
- 输出为纯文本文件（.txt）

### 4.4 撤回与重做
- `Ctrl+Z`：撤回上一步操作
- `Ctrl+Y`：重做已撤回的操作
- 底部工具栏显示当前撤回栈深度

## 六、常见问题

### Q: 启动时提示「核心引擎加载失败」
**原因**：`resources/native/text-unifier-core.win32-x64-msvc.node` 文件缺失或损坏。  
**解决**：重新解压便携版 ZIP，确保 `native/` 目录完整。

### Q: 拖拽文件后无反应
**原因**：Electron 文件路径读取问题。  
**解决**：使用「点击 + 按钮 → 文件对话框」方式添加文件。

### Q: 文件编码识别错误
**支持编码**：UTF-8（含 BOM）、UTF-16 LE/BE、GBK、GB2312、Shift-JIS、EUC-JP、ISO-2022-JP、Big5、EUC-KR
