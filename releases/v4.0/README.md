# Text Unifier V4.0 — 文档终版确定器

纯本地处理的 TXT 文档合并去重工具，支持文件间链式重叠合并、繁简转换、搜索替换、文档对比。

## 系统要求

- **操作系统**: Windows 10+ (x64)
- **运行时**: 无需额外安装（内置 WebView2）
- **内存**: 最低 512MB，推荐 4GB+
- **磁盘**: 约 200MB

## 快速开始

1. 下载 `TextUnifier_Portable_v4.0.zip` 并解压
2. 双击 `Text Unifier.exe` 运行
3. 拖拽 .txt 文件到窗口，或点击「+」按钮添加
4. 查看链式重叠合并结果，使用连接点列表切换合并/保留
5. 通过搜索替换或繁简转换清洗文本
6. 点击「导出合并文档」保存为 UTF-8 BOM .txt

## 隐私声明

所有处理在本地完成，数据不会上传到任何服务器。
