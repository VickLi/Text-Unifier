# Text Unifier V4.0 发布说明

> **版本**: V4.0.0
> **发布日期**: 2026-05-22
> **桌面框架**: Electron 31 + napi-rs (Rust)

## 核心变更（V3.3 → V4.0）

| 类别 | 变更 |
| :--- | :--- |
| **数据模型** | 从「段落列表 + 勾选」模型 → 「连续文本 + 连接点」模型 |
| **合并引擎** | 新增链式重叠合并（最长后缀-前缀匹配），替代 V3.3 段落去重 |
| **内容清洗** | 精简为繁简转换 + 全角↔半角；新增搜索替换模块 |
| **模块删除** | 移除章节工具、排版增强、关键词搜索（V3.3 旧版） |
| **桌面框架** | 保留 Electron 31（Tauri 2.x Demo 评估后延迟至 V4.1+） |

## 模块清单

- A — 文件输入与排序（100% 保留）
- B — 链式重叠合并引擎（Rust napi-rs）
- C — 连接点列表（V4.0 重构）
- D — 预览区（连续文本 + Minimap）
- E — 内容清洗（繁简 + 全半角 + 搜索替换）
- H — 撤回栈（5 步 FIFO + Ctrl+Z/Y）
- I — 文档对比（LCS 双栏）
- J — 导出（UTF-8 BOM + CRLF）
- L — 合并设置（阈值 10~500）
- M — 搜索替换（Ctrl+H 唤起）
