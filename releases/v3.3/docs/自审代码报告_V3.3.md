## 四、逻辑漏洞检测

| 检查项 | 结论 | 说明 |
|:-------|:----:|:-----|
| `removeFile` 单文件删除后空列表 | ✅ | `shouldReset` 检查确保清空 |
| `removeFile` 重复组刷新 | ✅ | 过滤 `occurrence_count > 1`（符合 V1.1 规则） |
| `toggleFullWidth` 空文本 | ✅ | `checkedParas.length === 0` 时不操作 |
| `searchNextKeyword` wrap-around | ✅ | 搜到末尾后从头搜索 |
| `searchNextKeyword` 无匹配 | ✅ | 返回 `null`，高亮消退 |
| `deleteAllKeywordMatches` 空关键词 | ✅ | 提前返回 state |
| `Minimap` 空段落 | ✅ | `items.length > 0` 条件渲染 |
| `ParagraphIndicator` 优先级 | ✅ | deleted > modified > normal |
