## 重要声明

V3.3 **无任何 IPC 层变更、无任何 Rust napi 变更、无任何 Electron Main Process 变更**。所有 V3.2 的 IPC handler（6 个）和 napi 函数（4 个）100% 保留。

V3.3 的全部新功能（双向切换按钮、段落指示器、Minimap、关键词搜索/删除、文件删除刷新重复组、导出保留撤回栈）均为 **纯前端 TypeScript** 实现。

本文档对 V3.2 接口进行**确认性复述**，并补充 V3.3 新增的纯前端接口定义。

### 3.4 KeywordSearchBar API（`src/components/KeywordSearchBar.tsx`）

#### `KeywordSearchBar`

| 属性 | 类型 | 说明 |
| :--- | :--- | :--- |
| `keywords` | `string` | 逗号分隔的关键词（来自 CleanOptions.filterKeywords） |

### 3.5 高亮消退 Hook（`src/hooks/useHighlightTimeout.ts`）

```typescript
/**
 * 高亮消退 Hook
 * 当 highlightedLineIndex 变更时，启动 3 秒计时器，到期后重置为 null
 */
function useHighlightTimeout(
    highlightedLineIndex: number | null,
    onClear: () => void
) {
    useEffect(() => {
        if (highlightedLineIndex === null) return;
        const timer = setTimeout(() => onClear(), 3000);
        return () => clearTimeout(timer);
    }, [highlightedLineIndex]);
}
```

### 3.6 段落状态判定（`src/utils/paragraphState.ts`）

```typescript
/**
 * 判定段落渲染状态
 *
 * 优先级：deleted > modified > normal
 */
export function getParagraphState(
    paragraphId: string,
    checkedMap: Map<string, boolean>,
    modifiedIds: Set<string>
): 'normal' | 'deleted' | 'modified' {
    if (checkedMap.get(paragraphId) === false) return 'deleted';
    if (modifiedIds.has(paragraphId)) return 'modified';
    return 'normal';
}
```
