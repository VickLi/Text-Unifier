## 更新内容

### UX 改进（9 项交互打磨）

| 区域 | V3.2 | V3.3 |
| :--- | :--- | :--- |
| 文件芯片栏按钮 | 文字按钮 | **36×36 方形 + 图标按钮** |
| 芯片 Tooltip | 无 | **悬停显示完整文件名** |
| 重复组 Tooltip | 无 | **悬停显示完整段落文字** |
| 重复组刷新 | 仅导入/排序时 | **增删文件即时更新** |
| 预览段落渲染 | 删除段落隐藏 | **保留 + 删除线 + 红色指示器** |
| 预览条 | 无 | **左侧 3px 彩色竖线 + 右侧 Minimap** |
| 清洗面板 | Checkbox / select | **双向切换按钮 (ToggleButton)** |
| 广告过滤 | 仅关键词输入 | **+ 搜索下一个 + 一键删除按钮** |
| 行尾页码 | 存在 | **移除** |
| 工具修改标记 | 无 | **橙色指示器 (ParagraphIndicator)** |
| 导出后撤销 | 不保留 | **保留撤回栈 + 还原按钮** |
