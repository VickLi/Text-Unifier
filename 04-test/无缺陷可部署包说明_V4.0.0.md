## 四、可部署代码包结构

```
03-code/
├── src/                    # React 前端（13 个组件）
│   ├── components/         # 全部 UI 组件
│   ├── store/useStore.ts   # Zustand Store（28字段，30动作）
│   ├── types/index.ts      # 完整类型定义（含 bothOnly）
│   └── utils/              # IPC 通信 + 工具函数
├── electron/               # Electron 主进程（5 个 IPC 通道）
│   ├── main.ts             # 5 个 IPC handler
│   ├── preload.ts          # contextBridge
│   └── preload.d.ts        # 类型定义
├── native/                 # Rust napi-rs 原生模块（3 个 napi 函数）
│   ├── src/
│   │   ├── lib.rs              # napi 导出入口
│   │   ├── text_normalizer.rs  # 文本归一化
│   │   ├── encoding_detector.rs # 编码探测链
│   │   └── chain_merger.rs     # 链式重叠合并
│   └── ...
├── package.json
├── vite.config.ts
├── tailwind.config.js
├── tsconfig.json
└── electron-builder.yml
```

## 五、构建与运行

```powershell
# 1. 安装依赖
cd 03-code
npm install

# 2. 编译原生模块
npm run napi:build

# 3. 开发模式
npm run electron:dev

# 4. 生产打包
npm run electron:build
```
