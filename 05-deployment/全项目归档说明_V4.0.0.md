## 三、归档包生成说明

### 3.1 方式一：Git 仓库克隆（推荐）

```bash
git clone https://github.com/VickLi/Text-Unifier.git
git checkout v4.0.0
```

克隆后即为完整归档包，包含全部阶段文档和源码。

### 3.2 方式二：手动打包

```powershell
# 从项目根目录执行
$archiveDir = "Text-Unifier-V4.0.0-Archive"
mkdir $archiveDir -Force

# 复制各阶段文档
Copy-Item "01-requirements" "$archiveDir/" -Recurse
Copy-Item "02-architecture" "$archiveDir/" -Recurse
Copy-Item "03-code" "$archiveDir/" -Recurse
Copy-Item "04-test" "$archiveDir/" -Recurse
Copy-Item "05-deployment" "$archiveDir/" -Recurse
Copy-Item "docs" "$archiveDir/" -Recurse
Copy-Item "scripts" "$archiveDir/" -Recurse

# 复制配置文件
Copy-Item "package.json" "$archiveDir/"
Copy-Item ".gitignore" "$archiveDir/"
Copy-Item "README.md" "$archiveDir/"
Copy-Item "electron-builder.yml" "$archiveDir/"
Copy-Item "vite.config.ts" "$archiveDir/"
Copy-Item "tailwind.config.js" "$archiveDir/"
Copy-Item "postcss.config.js" "$archiveDir/"
Copy-Item "tsconfig.json" "$archiveDir/"
Copy-Item "tsconfig.electron.json" "$archiveDir/"
Copy-Item "tsconfig.node.json" "$archiveDir/"

# 排除无需归档的目录
$excludeDirs = @("node_modules", "dist", "dist-electron", "release", "native/target", ".venv", "src-tauri/target")
foreach ($dir in $excludeDirs) {
    Remove-Item "$archiveDir/$dir" -Recurse -Force -EA SilentlyContinue
}

# 压缩为 ZIP
Compress-Archive "$archiveDir\*" "Text-Unifier-V4.0.0-Archive.zip" -Force
Remove-Item $archiveDir -Recurse -Force
```
