# Text Unifier — 用户使用手册

> **版本**: V4.0.0
> **适用平台**: Windows 10 / 11 (x64) | macOS 12+ | Linux
> **技术架构**: Electron 31 + napi-rs (Rust) + React 18
> **最后更新**: 2026-05-22

---

## 一、产品概述

**Text Unifier（文档终版确定器）** 是一款**完全离线**的桌面工具，专注于多 TXT 文件的智能合并、去重、内容清洗、预览编辑与文档对比。

### 核心功能

| 功能 | 说明 |
|:----|:------|
| **链式重叠合并** | 智能检测文件间的重叠内容，自动拼接或提示用户确认 |
| **内容清洗** | 繁简转换、全角半角转换、搜索替换 |
| **可编辑预览** | 连续文本预览区，支持手动编辑和撤回 |
| **文档对比** | 双栏 LCS 段落对齐，四色渲染差异 |
| **一键导出** | 纯净 UTF-8 TXT 导出，排除连接标记 |

## 二、安装说明

### 2.1 便携版（推荐）

1. 下载 `TextUnifier_Portable_v4.0.0.zip`
2. 解压到任意目录（建议：`C:\Program Files\TextUnifier\` 或桌面）
3. 双击 `Text Unifier.exe` 启动
4. （可选）右键 `Text Unifier.exe` → 固定到任务栏 / 发送到桌面快捷方式

### 2.2 安装版（批处理脚本）

1. 解压便携版 ZIP 到任意目录
2. 以 **管理员身份** 运行 `installer\安装程序.cmd`
3. 按提示选择安装路径（默认 `C:\Program Files\TextUnifier\`）
4. 安装完成后桌面自动创建快捷方式

### 2.3 系统要求

| 项目 | 最低要求 |
|:----|:---------|
| 操作系统 | Windows 10 x64 或更高 / macOS 12+ / Linux |
| 内存 | 1 GB |
| 磁盘空间 | 500 MB |
| 依赖 | 无（内置 Electron 运行时） |

## 三、卸载说明

### 3.1 便携版

直接删除解压目录即可。如已创建快捷方式，手动删除。

### 3.2 安装版

以 **管理员身份** 运行 `installer\卸载程序.cmd`，或手动：
1. 删除安装目录（默认 `C:\Program Files\TextUnifier\`）
2. 删除桌面快捷方式
3. 删除开始菜单快捷方式

> **注意**：本应用为绿色软件，不写注册表，卸载仅需删除文件。

## 四、快速入门

### 4.1 添加文件

| 方式 | 操作 |
|:----|:------|
| **拖拽** | 从 Windows 资源管理器将 `.txt` 文件拖入应用窗口（全窗口蓝色遮罩提示） |
| **点击添加** | 点击芯片栏末尾的 `+` 按钮，在文件对话框中选择 `.txt` 文件 |

> 支持多选文件，**仅接受 `.txt` 格式**。

### 4.2 合并去重模式

**功能**：对多个 `.txt` 文件进行链式重叠合并，智能处理文件衔接处的重复内容。

操作流程：
1. 添加 2 个或更多 `.txt` 文件
2. 第 1 个文件标记为 ★ 主文件（完整保留）
3. 左侧「连接点」面板列出所有文件衔接处的重叠信息
4. 查看每个连接点的重叠长度和 snippet
5. 重叠 ≥ 阈值（默认 50 字符）→ 自动合并（灰色标记）
6. 重叠 < 阈值 → 待确认（高亮标记），可切换合并/保留
7. 点击底部「⏎ 导出」保存结果

### 4.3 预览区编辑

- **手动编辑**：直接在预览区修改文本（连接标记不可编辑）
- **撤回/重做**：`Ctrl+Z` 撤回 / `Ctrl+Y` 重做（最多 5 步）
- **Minimap**：右侧 30px 缩略图，点击跳转

### 4.4 内容清洗

1. 右侧「清洗」面板
2. **繁简转换**：点击 ToggleButton 进行双向转换
3. **全角半角转换**：点击 ToggleButton 进行双向转换
4. **搜索替换**：Ctrl+H 唤起搜索框，支持高亮、逐个替换、全部替换

### 4.5 文档对比模式

1. 切换到「📋 文档对比」标签
2. 添加 2 个 `.txt` 文件
3. 查看四色渲染差异：
   - 🟢 **绿色**：两栏相同段落
   - 🔴 **红色**：左栏独有
   - 🔵 **蓝色**：右栏独有
   - ⚪ **灰色**：内容相似但有差异（词级高亮）
4. 底部统计栏查看对比数据

### 4.6 导出

- 点击底部「⏎ 导出」或按 `Ctrl+S`
- 导出内容为预览区完整文本（连接标记不写入）
- 默认文件名：`{第一个文件名}_merged.txt`
- 格式：UTF-8 BOM、CRLF 换行

## 七、常见问题

### Q: 启动时提示「核心引擎加载失败」
**原因**：`native/text-unifier-core.win32-x64-msvc.node` 文件缺失或损坏。
**解决**：重新解压便携版 ZIP，确保 `native/` 目录完整。

### Q: 拖拽文件后无反应
**原因**：Electron 文件路径读取问题。
**解决**：使用「点击 + 按钮 → 文件对话框」方式添加文件，或重启应用。

### Q: 文件编码识别错误
**支持编码**：UTF-8（含 BOM）、UTF-16 LE/BE、GB18030、Windows-1252、Shift-JIS
**解决**：应用会尝试所有编码探测链，最终兜底 UTF-8。

### Q: 如何调整合并灵敏度？
**解决**：点击标题栏 [≡] 菜单 →「合并设置」，调整重叠阈值（默认 50，范围 10~500）。

### Q: 应用是否会上传我的文件？
**答**：**完全不会**。Text Unifier 是 100% 离线的桌面应用，不发起任何网络请求，所有处理在本地完成。
