## 一、V3.3 变更总览

| 区域 | V3.2 | V3.3 | 变更类型 |
| :--- | :--- | :--- | :--- |
| 文件芯片栏按钮 | 文字按钮，可能折行 | **36×36 方形 + 图标** | 修复 |
| 芯片 Tooltip | 无 | **悬停显示完整文件名** | 新增 |
| 重复组 Tooltip | 无 | **悬停显示完整段落文字** | 新增 |
| 重复组刷新 | 仅导入/排序时 | **增删文件即时更新** | 修复 |
| 预览段落渲染 | 删除段落隐藏 | **保留 + 删除线 + 红色指示器** | 重构 |
| 预览条 | 无 | **左侧 3px 彩色竖线 + 右侧 minimap** | 新增 |
| 清洗面板 | Checkbox / select | **双向切换按钮** | 重构 |
| 广告过滤 | 仅关键词输入 | **+ 搜索下一个 + 一键删除按钮** | 新增 |
| 行尾页码 | 存在 | **移除** | 删除 |
| 工具修改标记 | 无 | **橙色指示器** | 新增 |
| 导出后撤销 | 不保留 | **保留撤回栈 + 还原按钮** | 增强 |

### 3.1 文件芯片栏（RQ-01）

```text
+------------------------------------------------------------------------------------------+
|  [📄 全本.txt ★ ✕] [📄 卷一.txt ✕] [📄 卷二.txt ✕] ... [📄 卷十.txt ✕]  ┃  [+]  ┃  |
```

- 芯片：`inline-flex items-center px-2.5 py-1 rounded-full text-xs bg-blue-50 border border-blue-200`

- 删除 ×：`ml-1 text-gray-400 hover:text-red-500`
- `+` 按钮：`w-9 h-9 flex items-center justify-center rounded-lg bg-gray-100 hover:bg-blue-50 hover:text-blue-600 border border-dashed border-gray-300`
- 整个 bar：`flex items-center gap-1.5 overflow-x-auto h-10`（固定 40px 高，内部横向滚动）

### 3.3 预览段落 — 三种状态渲染（RQ-04/RQ-08）

#### 绿色 = 正常段落（保留 + 未修改）

```text
┃ ▎  这是第一段独有的内容。
┃     这是第一段独有的第二句内容。
┃ ☑                            [来源: A.txt]
  ↑ 3px 绿色竖线
```

#### 红色 = 已删除段落（取消勾选）

```text
┃ ▎  ──被排除的段落内容────────
┃     ──这是第二行─────────────
┃ ☐   已排除                    [来源: B.txt]
  ↑ 3px 红色竖线  +  text-gray-400 line-through opacity-50
```

#### 橙色 = 被工具修改的段落

```text
┃ ▎  排版修改后的段落内容。
┃ ☑                            [来源: C.txt] (已修改)
  ↑ 3px 橙色竖线  +  底部"已修改"标记
```

### 3.4 Minimap 缩略图（RQ-04）

```text
┌─ 预览区 ───────────────────────┐  ┌─ minimap ─┐
│                                │  │ ▍ 绿       │
│ ▎ 段落1（绿色竖线）  正常       │  │ ▍ 绿       │

│                                │  │ ▍ 红       │  ← 鼠标悬停高亮
│ ▎ 段落3（红色竖线）  已删除     │  │ ▍ 绿       │
│ ──被删除内容─────               │  │ ▍ 绿       │
│                                │  │ ▍ 绿       │
│ ▎ 段落4（绿色竖线）  正常       │  │ ▍ 绿       │
│                                │  │ ▍          │
└────────────────────────────────┘  └────────────┘
         ↑                                    ↑
    3px 彩色竖线                         30px minimap
```

**Minimap 交互**：
- 悬停色条 → 色条亮度 +20% + 显示该段落前 20 字 tooltip
- 点击色条 → 预览区 `scrollTo` 滚动到对应段落
- 色条 2px 高 + 1px `gap` → 1000 段 ≈ 3000px 可滚动区域

### 3.6 底部工具栏（RQ-09）

```text
+------------------------------------------------------------------------------------------+
|  [☐ 全选] [☑ 取消全选]  已排除 1/6 段  |  ↶ 撤回 (3/5)  ↷ 重做  |  ↶ 还原  ⏎ 导出     |
|                                         |                        |  ↑ 导出前最后一步还原 |
+------------------------------------------------------------------------------------------+
```

- `↶ 撤回 (3/5)`：可撤回时显示当前栈深度，不可撤回时灰色
- `↷ 重做`：可重做时显示，不可时灰色
- `↶ 还原`：导出按钮旁独立还原按钮，恢复至导出前快照

## 四、新增/变更组件规格

### 4.1 新增组件

#### ParagraphIndicator（段落状态指示器）

| 属性 | 类型 | 说明 |
| :--- | :--- | :--- |
| `state` | `'normal' \| 'deleted' \| 'modified'` | 段落状态 |
| `width` | `number` | 竖线宽度，默认 3px |

**样式**：
- `normal` → `border-l-[3px] border-l-green-500 h-full`
- `deleted` → `border-l-[3px] border-l-red-400 h-full`
- `modified` → `border-l-[3px] border-l-orange-400 h-full`

---

#### Minimap（预览缩略图）

| 属性 | 类型 | 说明 |
| :--- | :--- | :--- |
| `items` | `MinimapItem[]` | 段落色条列表 |
| `onItemClick` | `(index: number) => void` | 点击跳转 |
| `height` | `number` | minimap 总高度（跟随预览区） |

**MinimapItem**：
```typescript
interface MinimapItem {
    color: 'green' | 'red' | 'orange';
    tooltip: string;  // 段落前 20 字
}
```

---

#### ToggleButton（双向切换按钮）

| 属性 | 类型 | 说明 |
| :--- | :--- | :--- |
| `labelForward` | `string` | 正向标签（如「全角→半角」） |
| `labelBackward` | `string` | 反向标签（如「半角→全角」） |
| `isToggled` | `boolean` | 是否已切换至反向状态 |
| `onToggle` | `() => void` | 点击回调 |

**样式**：
- 未切换：`bg-blue-500 text-white`
- 已切换：`bg-gray-500 text-white`

---

#### KeywordSearchBar（关键词搜索栏）

| 属性 | 类型 | 说明 |
| :--- | :--- | :--- |
| `keywords` | `string` | 逗号分隔的关键词 |
| `text` | `string` | 待搜索的全文 |
| `onDeleteAll` | `() => void` | 一键删除回调 |
| `currentPos` | `number` | 当前搜索位置（由内部维护） |

## 六、新增交互流程

### 6.1 双向切换按钮交互

```text
按钮初始: [全角→半角]  bg-blue-500
              │
              ▼ 用户点击
  ┌─ toHalfWidth(text) ──────────────────┐
  │ 所有全角数字字母转为半角              │
  └──────────────────────────────────────┘
              │
              ▼
  按钮变为: [半角→全角]  bg-gray-500
  (灰色表示"已转换，点此还原")
              │
              ▼ 用户再次点击
  ┌─ toFullWidth(text) ──────────────────┐
  │ 所有半角数字字母恢复全角              │
  └──────────────────────────────────────┘
              │
              ▼
  按钮恢复: [全角→半角]  bg-blue-500
```

### 6.2 删除文件后重复组刷新

```text
用户点击芯片 [✕] 删除文件
              │
              ▼
[removeFile(path) → Store 更新]
              │
    ┌─────────┴─────────┐
    │ sortedFileList     │  removed_file 移除
    │ duplicateGroups    │  → 重新计算
    │ previewParagraphs  │  → 重新分析
    └─────────┬─────────┘
              │
              ▼
[遍历所有重复组]
  ├─ 移除 sources 中与 removed_file 匹配的条目
  ├─ 重新计算 occurrence_count
  └─ 过滤 occurrence_count ≤ 1 的组
              │
              ▼
[保留用户勾选状态 (content_hash 匹配)]
              │
              ▼
[UI 更新: 左侧重复组列表 + 预览区]
```

### 6.3 Minimap 与预览滚动联动

