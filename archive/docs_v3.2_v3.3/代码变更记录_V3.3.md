## 三、变更文件

### 3.1 `src/types/index.ts`

- `CleanOptions` 移除 `removeLineEndNumbers: boolean` 字段
- 新增 `MinimapItem` 接口 (`color: 'green'|'red'|'orange', tooltip: string`)

### 3.2 `src/store/defaults.ts`

- `DEFAULT_CLEAN_OPTIONS` 移除 `removeLineEndNumbers`
- 新增 `DEFAULT_V3_3_STATE` 导出（6 个字段）

### 3.3 `src/store/useStore.ts`（核心变更）

**新增 8 个状态字段**：
| 字段 | 类型 | 说明 |
|:-----|:-----|:-----|
| `isFullWidthConverted` | `boolean` | 全角↔半角双向切换状态 |
| `isTraditionalConverted` | `boolean` | 繁简双向切换状态 |
| `minimapItems` | `MinimapItem[]` | 预览条色条数据 |
| `keywordSearchIndex` | `number` | 当前搜索行号 |
| `highlightedLineIndex` | `number\|null` | 当前高亮行号 |
| `modifiedParagraphIds` | `Set<string>` | 被工具修改的段落 ID |

**新增 9 个 Action**：
- `toggleFullWidth()` — 全角↔半角 + 标记修改
- `toggleTraditional()` — 繁简切换状态
- `_updateMinimap()` — 派生 minimapItems
- `searchNextKeyword()` — 搜索下一个 + wrap-around
- `deleteAllKeywordMatches()` — 一键删除匹配行
- `_markModifiedParagraphs()` — 标记修改段落
- `jumpToParagraph()` — Minimap 跳转

**变更 Action**：
- `removeFile()` — RQ-03 自动刷新重复组
- `resetSession()` — 重置 V3.3 默认值

**新增辅助函数**：
- `toHalfWidth(text)` — 全角→半角（纯 TS）
- `toFullWidth(text)` — 半角→全角（反向恢复）

### 3.4 `src/components/CleanPanel.tsx`（重构）

- 繁简转换：`<select>` 下拉框 → `ToggleButton`「繁→简」⇄「简→繁」
- 全角半角：Checkbox → `ToggleButton`「全角→半角」⇄「半角→全角」
- RQ-07：移除「清除行尾页码」复选框
- RQ-06：新增 `KeywordSearchBar`（搜索下一个 + 一键删除）
- RQ-06：`Ctrl+F` → 聚焦搜索框 / `F3` → 搜索下一个

### 3.5 `src/components/PreviewPanel.tsx`

- 导入 `Minimap`, `useHighlightTimeout`
- 添加 V3.3 状态读写（`minimapItems`, `modifiedParagraphIds`, `highlightedLineIndex`）
- Minimap 渲染于预览区右侧
- 段落映射传递 `index`, `isModified`, `highlightedLineIndex`

### 3.6 `src/components/PreviewParagraph.tsx`

- 新增 `ParagraphIndicator` 彩色指示器（绿/红/橙 3px 竖线）
- 已删除段落：`line-through` + `text-gray-400` + `opacity-50`（不再隐藏）
- 工具修改标记：橙色「已修改」徽章
- `data-para-index` 属性（Minimap 跳转用）
- Props 扩展：`index`, `isModified`, `highlightedLineIndex`

### 3.7 `src/components/FileChipBar.tsx`

- RQ-01：按钮改为 36×36 纯 `+` 图标 + Tooltip「添加 .txt 文件」
