## 四、目录重组织（第二轮清理）

依据项目分类规范，将根目录下的分散目录移至对应阶段目录下：

### 4.1 移至 `03-code/`（活跃源码 + 源码参考）

| 原始位置 | 目标位置 | 说明 |
|:---------|:---------|:------|

| `native/` | `03-code/native/` | Rust napi-rs 原生模块源码 |

| `src-tauri/` | `03-code/src-tauri/` | Tauri 源码（V4.1+ 参考） |

### 4.2 移至 `04-test/`（测试数据）

| 原始位置 | 目标位置 | 说明 |
|:---------|:---------|:------|
| `test_data/` | `04-test/test_data/` | 功能测试/性能测试/安全测试数据 |

### 4.3 移至 `05-deployment/`（资源文件）

| 原始位置 | 目标位置 | 说明 |
|:---------|:---------|:------|

| `public/` | `05-deployment/public/` | 前端公共资源（更新 Vite `publicDir` 配置） |

### 4.4 配置文件更新

| 文件 | 变更内容 |
|:-----|:---------|
| `tsconfig.json` | `include: ["03-code/src"]` |
| `tsconfig.electron.json` | `rootDir: "03-code/electron"`, `include: ["03-code/electron"]` |
| `index.html` | 脚本路径 `/src/main.tsx` → `/03-code/src/main.tsx` |
| `package.json` | `napi:build` → `cd 03-code/native`；`electron:ts` → `node 03-code/scripts/...` |
| `electron-builder.yml` | 所有 native 路径加 `03-code/` 前缀；`buildResources` → `05-deployment/icons` |
| `vite.config.ts` | 新增 `publicDir: '05-deployment/public'` |

## 五、根目录结构总览（最终状态）

### 目录

| 目录 | 归属 | 作用 |
|:-----|:----|:------|
| `.vscode/` | 开发工具 | VS Code 编辑器配置（tasks.json, settings.json 等） |
| `01-requirements/` | 阶段产出 | 需求阶段文档（PRD、交互原型） |
| `02-architecture/` | 阶段产出 | 架构阶段文档（架构/接口/数据库设计、技术选型） |
| `03-code/` | 阶段产出 | **代码阶段 — 源码主目录**（含 `src/`, `electron/`, `native/`, `scripts/`, `demo-tauri/`, `src-tauri/`） |
| `04-test/` | 阶段产出 | 测试阶段文档 + 测试数据（`test_data/`） |
| `05-deployment/` | 阶段产出 | 部署阶段产出（含便携版安装包、安装/卸载脚本、文档、资源文件） |
| `archive/` | 历史归档 | 所有历史版本（v1.0~v3.3）的文档与发布包归档 |
| `releases/` | 版本发布 | electron-builder 生成的各版本发布包（v3.0~v3.3） |

### 根目录文件

| 文件 | 作用 |
|:-----|:------|
| `package.json` | Node.js 项目配置（依赖、构建脚本） |
| `package-lock.json` | npm 依赖版本锁定 |
| `tsconfig.json` | TypeScript 前端编译配置（指向 `03-code/src`） |
| `tsconfig.electron.json` | TypeScript Electron 编译配置（指向 `03-code/electron`） |
| `tsconfig.node.json` | TypeScript Node 工具编译配置 |
| `vite.config.ts` | Vite 构建配置（含 `publicDir` 指向 `05-deployment/public`） |
| `electron-builder.yml` | Electron 打包配置（指向 `03-code/native` 和 `05-deployment/icons`） |
| `tailwind.config.js` | Tailwind CSS 样式配置 |
| `postcss.config.js` | PostCSS 配置 |
| `index.html` | 应用入口 HTML（脚本路径指向 `03-code/src/main.tsx`） |
| `.gitignore` | Git 忽略规则配置 |
| `README.md` | 项目说明文档 |
| `Text Unifier.code-workspace` | VS Code 多根工作区配置 |
| `icon.ico` | Windows 应用图标（根目录保留供 electron-builder 发现） |
| `128x128.png`, `128x128@2x.png`, `32x32.png` | 应用图标 PNG 备用 |
